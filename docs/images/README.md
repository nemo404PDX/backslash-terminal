# Backslash screenshots

README artwork and screenshots live in this directory. The current gallery uses `backslash-hero.png`, `Screenshot-05-wide.png` and `Screenshot-01.png` through `Screenshot-08.png`. The `.afdesign` files retain editable artwork sources.

Suggested captures:

- `crt-appearance.png`: CRT controls and a representative terminal view.
- `retro-bezel.png`: bezel presets, badge and aperture layout.
- `ssh-profile-shell.png`: remote shell selection for a demo SSH profile.
- `ssh-profile-restore.png`: Scan SSH hosts and Add/Restore workflow.

Use a test profile with demo names and paths. Remove or redact passwords, private keys, tokens, usernames, private hostnames/IPs, personal paths and sensitive command/history output before sharing. Check the entire image, including tabs, prompts, notifications and background windows.

Use PNG with short lowercase hyphenated filenames. Aim for approximately 1200–1600 pixels wide for full-window captures. Crop feature details tightly while keeping controls readable; no artificial padding is required. Keep the whole bezel visible in bezel showcase images.

Once images exist, the main README can display them at around 800 pixels wide, with each image linked to its full-resolution version. Keep planned features out of current-feature screenshots. Add a relative image link to the [main README](../../README.md) only after the file exists and its contents have been reviewed.
