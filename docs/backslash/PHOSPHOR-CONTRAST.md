# Phosphor text contrast protection

Built-in phosphor tint remains monochrome at full strength. It does not restore ANSI hues to make text readable. `experimental.retroTerminalContrastGuard` defaults to true, inherits per appearance (including unfocused appearance), supports explicit false and null/reset, and survives setup transfer. Appearance exposes **Protect phosphor text contrast**. False retains the legacy tint/glow behavior. Effects off, zero tint and custom shaders bypass protection.

The ordinary Atlas text shader sees foreground and background before compositing. Its cell-color texture now carries the foreground plane as well as the background plane. For distinct source colors whose projected monochrome contrast is below 4.5:1, it separates their linear-light luminances toward dark and bright endpoints. Source light/dark polarity is retained; exact luminance ties select a polarity using backdrop lightness. Identical source colors remain untouched so deliberately concealed text is not revealed. This is a cell-role adjustment, not an edge detector or global brightness shift. Protected selection uses dark text on a lit cell so it remains a visible cue instead of collapsing into the ordinary dark background; a configured black selection uses the bright endpoint while protection is active. Cursor overlays use opposite monochrome endpoints. Ordinary text retains source polarity; selection/cursor feedback deliberately uses these stable cues. Color emoji/image glyphs retain their existing pass-through behavior rather than being treated as ordinary text.

With protection enabled, bloom coverage is bounded to [0,1] and added linear-light luminance is limited to 0.02 above the unblurred pixel. This retains a blurred halo without flooding dark letter interiors from a bright backdrop. Glow intensity still controls the blur contribution; high values can reach the automatic protection limit. This deliberately differs from legacy additive bloom. Protection off retains that exact legacy calculation. Black/White scanline behavior and its existing controls are unchanged.

No extra full-screen target, history buffer, animation or continuous-redraw dependency is introduced. The cell texture reserves a second cell-sized plane; foreground data is uploaded only while protection is active. Existing background-only upload behavior is retained when inactive. The external custom shader constant buffer remains 32 bytes; the existing private 48-byte retro buffer uses a previously reserved component for the guard flag. Hardware performance is not inferred from WARP tests.

## Preview and limits

The Settings preview always emits ASCII directory examples with ordinary ANSI backgrounds, indexed 48;5 backgrounds, truecolor 48;2 pairs with nearly equal luminance, and reverse video. These precede the original git/Write-Host sample and do not depend on Powerline glyph availability. They run through the same TermControl/Atlas rendering path as the edited profile.

Exact saturated monochrome endpoints cannot provide arbitrary contrast. Full blue (#0000FF) has luminance about 0.072, so its maximum opaque contrast against black is about 2.44:1. The guard uses the available selected endpoint rather than adding unrelated hues or whitening it. Very dark phosphors, antialiasing, transparency over external imagery and deliberately strong White scanlines can further limit readability; no universal accessibility ratio is promised. White scanlines at full intensity intentionally whiten their bands. Transparent holes remain transparent, including under White scanlines. Unfocused appearances can intentionally differ from the focused preview.

## Validation

`artifacts/phosphor-contrast-20261024` contains actual Atlas/WARP glyph readbacks, not just a formula simulation. `comparison.png` is pixel-identical legacy full-magenta, protected full-magenta and protected plus default-glow output, left to right. Separate captures include full glow, transparency and green phosphor plus 10% White scanlines. Synthetic directory text covers truecolor/indexed backgrounds, reverse video, selection, a full-box cursor, both polarities and identical-color concealment. Effects-off and zero-tint readbacks are exact identities. The legacy opacity/hue oracle runs with protection explicitly disabled.

For the nearly equal-luminance sample rows, measured rendered pixel contrast changes from about 1.43:1 to 4.48:1 without glow. Protected default/full-glow rows remain separated (about 4.12:1 or higher in this fixture). These are selected pixel ranges from a named WARP fixture, not a universal font/accessibility/hardware claim. Settings model and setup-transfer tests cover inherited true, explicit false, copy/serialization and null/reset. Native Settings toggle/reset and final portable verification are recorded in the delivery evidence.

Glitch, waves, grain and other animated effects remain deferred.
