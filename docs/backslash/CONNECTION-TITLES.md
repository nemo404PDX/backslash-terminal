# Connection identity in tabs and Ctrl+Tab

Implemented curated default: `backslash.showConnectionIdentity` is **true** when absent. Settings > Appearance > **Show connection identity in tab titles** is the discoverable opt-out. Turn it off and Save to restore ordinary Terminal titles. The JSON equivalent is `"backslash.showConnectionIdentity": false`. The toggle uses the existing Settings clone Save/Reset workflow, and re-evaluates existing tab/switcher titles when applied; no user settings file is rewritten merely to establish the default.

## Presentation and precedence

Connection or machine identity stays first; useful application titles follow it. Formatting is at the tab presentation layer. The terminal's application title remains available and continues changing normally; this does not blanket-enable `suppressApplicationTitle` or rewrite remote shell/SSH configuration. Ctrl+Tab already consumes `Tab.Title`, so it receives the same title and title-change notifications. Nonterminal panes retain their ordinary labels. In split tabs the active leaf pane drives the title; selecting a nonleaf split group retains the existing Multiple panes label.

| Launch | Example title | Identity source |
| --- | --- | --- |
| Plain local PowerShell/cmd | `LAPTOP · PowerShell · ~/project` | Local Windows computer name, chosen profile name, then current application title. |
| Generated SSH profile | `SSH build-box · ~/project` | Original generated parent/config alias, not an edited display name or a claimed remote hostname. |
| Generated SSH with selected shell | `SSH build-box · PowerShell 7 · ~/project` | Recognized shell choice; custom profile labels take precedence over the shell label. |
| Generated WSL profile | `WSL Ubuntu-24.04 · ~/project` | Original generated distro name, when the launch matches its generated command. |
| Manual/unfamiliar SSH or WSL launch | `SSH profile · My server · title` / `WSL profile · My distro · title` | Conservative launcher/source and profile labels; no arbitrary argument is promoted to a trusted target. |
| Unknown/script/wrapper launch | `Session · Developer tools · title` | Profile label; no Windows machine identity is asserted. |

Examples use illustrative names. SSH config aliases are useful configured identities, not verification of a remote hostname/IP/account. WSL names refer to the configured distribution. Direct launcher classification reads Windows argv only to distinguish known SSH/WSL launchers and a small allowlist of plain local shell flags. Scripts, command wrappers, remote PowerShell flags (including abbreviations/colon forms) and unknown launchers use the conservative fallback. It does not follow wrappers, inspect passwords/keys or connect/probe a machine. Nested SSH/WSL entered later inside a local shell is not detected; the prefix describes the original launch context, while the dynamic suffix remains application-supplied.

Explicit **runtime tab rename** wins exactly. Explicit profile `tabTitle` and launch/action `TabTitle`, including a string identical to the profile name, bypass automatic formatting. Their existing semantics remain: `tabTitle` establishes the starting title, and an application can still replace it unless `suppressApplicationTitle` is true. Explicit suppression also preserves the ordinary title. Resetting a runtime rename restores the current presentation policy. Profile display-name customizations are retained as a label beside the original generated target rather than being used to select that target.

Launch prefix, starting title and explicit-title intent are captured once in the terminal core. Reloading/retargeting a profile cannot relabel an already-running connection as the new target. A new/restarted connection captures current launch settings. Duplicate/move/persist arguments retain explicit title intent, but no longer turn an implicit starting profile title into an explicit override. Older persisted records that already contain a title are treated conservatively as explicit; no migration guesses which old strings were user-authored. Saved-group capture still excludes runtime tab renames and opens fresh sessions from current profiles.

Full title strings are retained for the tab tooltip, accessibility name and Ctrl+Tab item name; the tab header uses visual character ellipsis. No string truncation is stored. Long names/Unicode remain intact in the model. Native clipping, tooltip/accessibility and active-pane behavior still need visual/manual confirmation.

Focused fixtures cover default/false-copy serialization, explicit launch title equal to profile name, profile title precedence, current dynamic titles, local/SSH/WSL/wrapper fallbacks, renamed display versus original target, shell choice, unknown/changed commands, generated WSL parents, long Unicode strings and immutable metadata across settings reload plus OSC title updates. Full settings/control/profile/bezel and CRT/visibility/isolation checks accompany the fresh portable artifact. Exact results and hashes belong to its `connection-title-delivery.json`; source tests do not prove native Ctrl+Tab interactions.

Manual checklist in a fresh portable fixture: observe a local shell's initial and changing titles; switch among active local/WSL/SSH split leaves where connections already exist; test runtime rename/reset and explicit profile/CLI titles; toggle the Appearance setting with Save/Reset/reload; inspect long Unicode titles, tab tooltip and screen-reader names; compare Ctrl+Tab ordering and live labels; duplicate/move/tear out a tab and re-evaluate its identity; confirm the group-name TeachingTip still accepts editing and cancel/reopen restores focus. No real remote connection was opened by automated tests. Native UI verification remains blocked by the available computer-use runtime's Windows platform startup failure.

The naming build is also included in the subsequent [implemented saved-group startup slice](SAVED-TAB-GROUPS.md). Its separate startup selection preserves Default profile and previous-session defaults and does not modify installed Terminal settings. No commit/push, install/registration, credentials/security change or user-window disruption occurs here.
