## Validation

`Test-ExplorerIntegration.ps1 -EvidenceDirectory <fresh existing directory>` builds the real production header with `/W4 /WX`. Its executable uses only `HKCU\Software\Backslash.ExplorerIntegration.Tests\<pid>-<tick>` and removes that disposable tree. Tests cover enable, idempotency, repoint, partial repair, removal, missing entries, foreign/unmarked ownership and unknown values/subkeys. Real `CommandLineToArgvW` tests cover both Explorer substitutions, spaces, Unicode, metacharacters, semicolons, drive roots, trailing separators and UNC command boundaries. Folder checks exercise existing local/root paths and reject files, nonexistent and unsupported paths. The sandbox blocks registry writes; running this isolated fixture requires approval outside that sandbox.

`Test-ExplorerLaunch.ps1 -PortableDirectory <fresh matching dev portable> -EvidenceDirectory <fresh existing directory>` makes a separate runtime without user settings. Its synthetic PowerShell profile writes only observed cwd evidence, then exits. It checks normal launch, a literal nested semicolon/Unicode folder, drive root, and unchanged fixture settings. It never registers Explorer or sends input to existing windows.

`CommandlineTest::ParseExplorerFolder` adds real parser coverage to the inherited local TAEF suite. That package-based suite is not run automatically by the normal package build and has not been installed for this task.

Actual Explorer registration/menu invocation, interactive confirmation/layout/accessibility, multiple-copy UI actions and real UNC share launch remain manual acceptance checks. No live Explorer keys have been changed for this task. Build/test artifact identities and results are recorded in the task handoff.
